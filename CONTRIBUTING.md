# Contributing

Спасибо за интерес к Rocket.Chat Markdown+.

## Перед изменением

- Для исправления ошибки приложите обезличенный пример разметки, версию браузера, Tampermonkey и Rocket.Chat.
- Не прикладывайте токены, реальные сообщения, закрытые URL и идентификаторы комнат.
- Новая функция должна поддерживать конкретный пользовательский сценарий. Версия 1.x намеренно не содержит панели настроек или визуального конструктора. Универсальный `@match` ограничен HTTPS, `localhost` и `127.0.0.1`; runtime guard должен оставлять скрипт пассивным вне Rocket.Chat.

## Локальная проверка

Используйте Node.js 22:

```bash
npm ci
npx playwright install chromium firefox
npm run verify
```

Изменяйте файлы в `src`, затем выполняйте `npm run build`. Собранный
`dist/rocket-chat-markdown-plus.user.js` коммитится вместе с исходниками; CI проверяет его
воспроизводимость.

Изменение синтаксиса должно одновременно обновлять parser unit tests и `docs/SYNTAX.md`. Изменение интеграции с редактором должно иметь Playwright-сценарий. Изменение integration-слоя желательно проверять также командой `npm run test:compat`.

## Pull request

Опишите проблему, выбранное поведение и выполненные проверки. Для UI-проблемы приложите обезличенный скриншот. Публикация выполняется тегом `vX.Y.Z`: GitHub Actions подставляет версию тега в metadata итогового userscript и создаёт GitHub Release.
