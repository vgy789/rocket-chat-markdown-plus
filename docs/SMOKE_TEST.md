# Ручной smoke test перед релизом

Проверка выполняется в Chromium и Firefox с актуальным Tampermonkey и тестовой учётной записью локального или тестового Rocket.Chat. Не записывайте токены, личные сообщения и реальные имена на скриншоты.

## Подготовка

1. Соберите userscript командой `npm run build`.
2. Установите локальный `dist/rocket-chat-markdown-plus.user.js` в Tampermonkey.
3. Откройте тестовую комнату Rocket.Chat и DevTools Console.

## Сценарии

- Обычное сообщение отправляется без изменений и без сообщений в Console.
- Кнопка `::+` появляется один раз, открывает единую форму мышью и клавиатурой и не выходит за границы окна.
- Каждый из пяти пресетов заполняет тип, заголовок и цвет, но не меняет редактор до нажатия «Вставить»; при повторном открытии снова выбрана «Заметка».
- Заголовок и цвет обязательны, дополнительные параметры добавляются через раскрываемый раздел, сохраняются при смене пресета, а ошибки не закрывают форму и не теряют введённые значения.
- Обычный текст вместе с одним и несколькими callout-блоками отображается корректно у отправителя и другого участника.
- `title`, `color`, `thumb`, `image` и `collapsed` работают по отдельности; поля `image` и
  `collapsed` взаимоисключающие, а форма не позволяет вставить оба параметра.
- Ответ в тред сохраняет связь с исходным сообщением; отдельно проверяются канал и DM.
- При неизвестном типе, параметре и незакрытом блоке отправка не происходит, текст остаётся в редакторе, а ошибка содержит правильный номер строки.
- После перехода между комнатами и повторного mount редактора кнопка остаётся одна.
- На обычной HTTPS-странице без Rocket.Chat composer кнопка не появляется, auth-хранилище не читается, а сетевых запросов от userscript нет.
- Сообщение с одним блоком отправляется через REST, серверная ошибка показывается рядом с редактором и не приводит к повторной автоматической отправке.
- В E2EE-комнате callout блокируется понятным сообщением.
- Для полной проверки версий запустите `npm run test:compat`; сценарии и ограничения описаны в `docs/COMPATIBILITY.md`.

## Результат

Запишите версию браузера, Tampermonkey, userscript и дату проверки в описании GitHub Release.
