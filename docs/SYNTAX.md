# Синтаксис Rocket.Chat Markdown+

Callout начинается со строки `:::type` и заканчивается отдельной строкой `:::`. Имена типов и
параметров пишутся на английском в нижнем регистре.

```markdown
:::info
title=Заголовок
color=#3498db
thumb=https://example.com/thumb.png
image=https://example.com/image.png

Тело блока поддерживает **Markdown Rocket.Chat**.
:::
```

Пустая строка отделяет параметры от тела. Если параметров нет, текст можно писать сразу после открывающей строки.

Кнопка `::+` открывает форму с пятью готовыми стилями. Выбранный стиль задаёт тип, заголовок и цвет;
значения можно изменить до вставки. Дополнительные параметры находятся в раскрываемом разделе.
Форма сохраняет выбранный технический тип (`warning`, `info`, `success`, `error` или `note`).

## Типы

| Тип       | Цвет по умолчанию | Заголовок  |
| --------- | ----------------- | ---------- |
| `warning` | `#ff8800`         | Внимание   |
| `info`    | `#3498db`         | Информация |
| `success` | `#27ae60`         | Успех      |
| `error`   | `#e74c3c`         | Ошибка     |
| `note`    | `#9b59b6`         | Заметка    |

Заголовки автоматически отображаются на русском или английском в зависимости от языка страницы Rocket.Chat.

## Параметры

| Параметр    | Значение             | Назначение                           |
| ----------- | -------------------- | ------------------------------------ |
| `title`     | произвольный текст   | Заменяет стандартный заголовок       |
| `color`     | `#RGB` или `#RRGGBB` | Заменяет цвет типа                   |
| `thumb`     | абсолютный HTTPS URL | Добавляет небольшую миниатюру        |
| `image`     | абсолютный HTTPS URL | Добавляет крупное изображение        |
| `collapsed` | `true` или `false`   | Управляет свёрнутым состоянием медиа |

`image` и `collapsed=true` взаимоисключающие: Android-клиент Rocket.Chat не отображает их
одновременно. Используйте для одного блока либо `image`, либо `collapsed=true`.

Параметр можно указать только один раз. Неизвестные параметры считаются ошибкой — это защищает от незаметных опечаток.

Официальная схема `chat.sendMessage` также описывает `author_name`, `author_link`, `author_icon`,
`title_link`, `title_link_download`, `message_link`, `ts`, `fields`, `audio_url` и `video_url`.
Они пока не входят в Markdown+ v1: для них нужны дополнительные составные поля, медиа-валидация или отдельная проверка совместимости с конкретным сервером.

## Обычный текст и несколько блоков

```markdown
Начало сообщения.

:::info
Первый блок.
:::

Текст между блоками.

:::success
Второй блок.
:::

Конец сообщения.
```

Порядок обычного текста и attachments сохраняется настолько, насколько это позволяет модель сообщений Rocket.Chat: обычные фрагменты объединяются в `msg`, а блоки идут в массиве `attachments`.

## Проверка ошибок

Отправка будет остановлена, а черновик сохранён, если:

- тип или параметр неизвестен;
- параметр повторяется;
- блок не закрыт или закрывающая строка лишняя;
- `color`, `image`, `thumb` или `collapsed` имеют неверный формат;
- `image` и `collapsed=true` указаны вместе;
- один callout вложен в другой;
- сообщение отправляется в E2EE-комнату.

Вложенность и экранирование отдельной строки `:::` в теле в версии 1.x не поддерживаются.
